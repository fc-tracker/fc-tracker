# Security

FC-Tracker is published as source so its behaviour can be checked. If you find something that does not
match the list in the README ("What it does – and what it never does") – a network connection, data
leaving your PC, access to the game process – that is a security issue.

- Please report it to **hello@fc-tracker.com** (subject: "Security"), with the file and line if you
  have them. You will get an answer within a few days.
- Please do not post account-related details (EA ID, tokens, screenshots of your club) in public issues.

Only builds from https://www.fc-tracker.com/download and this repository's Releases page are official.
